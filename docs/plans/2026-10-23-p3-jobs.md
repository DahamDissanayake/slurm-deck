# Phase 3 — Jobs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Users submit, watch, extend, cancel and rerun Slurm batch jobs from the browser; the home dashboard updates live; the worker sends 30-minute expiry warnings and notify-when-free emails; one-click smoke test works.

**Architecture:** `web` renders job scripts with `sdcore` and hands them to deck-agent, which writes the job folder and runs `sbatch` **as the user**. Extensions run `scontrol update` as root inside deck-agent after it re-checks ownership, the cap (read from a new read-only settings view) and the partition MaxTime. A single in-process poller in `web` broadcasts cluster + job state over one WebSocket per browser.

**Tech Stack:** as Phase 2.

**Spec:** §4.4 (submit), §6.1, §6.2, §6.3, §6.10, §6.11 (personal usage is Phase 6), §6.12, §6.13, §13 scenarios 3, 4, 5, 9. **Roadmap:** shared names and fixed values.

## Global Constraints

- Roadmap constraints apply.
- Default time limit = setting `default_time_limit` (`08:00:00`). At submit, time ≤ the user's QoS `MaxWall` (read live via `sacctmgr show qos`; the legacy value for `normal` was 8 h — never assume it).
- Extension choices exactly +1 h, +2 h, +4 h. New total ≤ min(`extension_cap_hours`, partition MaxTime). Admins may exceed the cap but never the partition MaxTime. Refusal copy: "This would take the job to {total} h; the limit is {limit} h."
- Expiry warning at 30 min before the limit, once per job.
- Submit rate limit: `submit_rate_per_hour` (20) per account, counted from `jobs.submitted_at`.
- Job folder name `{job_name}_{YYYYmmdd_HHMMSS}` under `/shared/jobs/<username>/`.
- Other users' jobs never expose job name, script or paths (only username, state, pods, time).

## Review Focus

- **Two Extend clicks in quick succession** — must not add 2× hours past the cap; deck-agent serialises per job and re-reads the current limit. Test in Task 1.
- **A job that finished between page load and Cancel/Extend** — plain message "This job has already ended.", not a 500. Test in Task 3.
- **sbatch rejecting the script** (bad partition, QoS limit) — the user sees Slurm's own message, and no orphan job row stays. Test in Task 3.
- **Worker restarted mid-run** — no duplicate expiry warning for a job already warned. Test in Task 6.
- **Script path containing spaces or quotes** — rendered script stays valid and safe. Test in Task 2.

- Produces (verbs; caller user unless noted):
  - `job.submit` `{folder_name, script}` → `{job_id, folder}`: validates `folder_name` against `^[A-Za-z0-9._-]{1,80}$`; `validate_sbatch(script, username)` must return `[]` (else 422 with the problems); as the user: `mkdir -p /shared/jobs/<u>/<folder_name>` (mode 0770), write `job.sbatch` (0640), run `sbatch --parsable <path>`; returns the job id (first field before `;`).
  - `job.list` → caller's jobs from `squeue -u <u>` (`SQUEUE_FORMAT`) incl. names.
  - `job.show` `{job_id}` → `{owner, state, time_limit_s, run_time_s, std_out, std_err, work_dir, node, exit_code}` parsed from `scontrol show job -o`; refused (404 `not_found`) unless owner == caller or caller is admin.
  - `job.cancel` `{job_id}` → owner: `scancel` as the user; admin on someone else's job: `scancel` as root. Ended job → 409 `job_ended`.
  - `job.extend` `{job_id, hours}` → `hours` ∈ {1, 2, 4} (admin: any int 1–24); holds a per-job `threading.Lock`; re-reads `TimeLimit`; new total = limit + hours; caps: `extension_cap_hours` from `agent_settings` (skipped for admin) and partition `MaxTime`; runs `scontrol update JobId=<id> TimeLimit=<new>` as root; returns `{new_limit_s}`. Errors: 409 `job_ended`, 422 `over_cap` with `{total_h, limit_h}`.
  - `job.history` `{days (1–365), all_users: bool}` → `sacct -X -S now-<days>days --parsable2 --noheader --format=SACCT_FORMAT` as the user; `all_users` only for admins (`-a`, as root).
  - `joblog.read` `{job_id, stream: "out"|"err", offset: int, limit: int ≤ 1 MiB}` → raw bytes from the path in `job.show`; path must be inside the owner's job jail (`in_user_job_jail`); read as the owner (admins via `ops_identity`); response header `X-SD-Size` = file size.
  - `qos.limits` → `{max_wall_s: int | None, max_pods_per_user: int | None}` for the caller's QoS from `sacctmgr -n -P show assoc user=<u> format=qos` then `sacctmgr -n -P show qos <qos> format=MaxWall,MaxTRESPU`.
